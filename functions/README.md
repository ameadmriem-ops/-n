# إعداد ونشر خادم الإشعارات السحابي (Firebase Cloud Functions) لتطبيق BLACK ANIME

هذا المجلد يحتوي على كود دالة سحابية (Cloud Function) لمعالجة ونشر إشعارات **Firebase Cloud Messaging (FCM)** إلى كافة الأجهزة المشتركة في موضوع `all_users`.

## المميزات:
1. **Trigger تلقائي على Firestore**: بمجرد كتابة إشعار جديد في مجموعة `notification_queue` (عند إضافة حلقة جديدة أو إشعار يدوي)، تقوم الدالة تلقائيًا بإرساله لجميع المستخدمين المشتركين.
2. **منع التكرار (Idempotency)**: تفحص الدالة حالة الإشعار، وإذا تم إرساله مسبقاً تتجاهله فوراً لتجنب إزعاج المستخدمين.
3. **نقطة وصول آمنة HTTPS**: تدعم إرسال الإشعار بعد التحقق من كود الإدارة السري (`adminKey`).
4. **تحديث حالة الإشعار**: تُسجّل نجاح أو فشل الإرسال ومعرف رسالة FCM في Firestore لتتبعه في لوحة الإدارة.

## طريقة النشر السريعة:
1. تأكد من تثبيت Firebase CLI على جهازك:
   ```bash
   npm install -g firebase-tools
   ```
2. سجل الدخول إلى حسابك في Firebase:
   ```bash
   firebase login
   ```
3. توجه إلى مجلد المشروع وقم بربط المشروع:
   ```bash
   firebase use hamza-4b70c
   ```
4. قم بنشر الدوال السحابية:
   ```bash
   firebase deploy --only functions
   ```
